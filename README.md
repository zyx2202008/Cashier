# 出纳管理 Cashier 1.3.0

当前交付版支持整账套`.cashier`导出和导入为新账套，并支持六类基础资料的Excel模板、导出、编辑回导、逐行校验及整批提交。

入口：系统工具 → 导入导出。使用步骤见 [数据导入导出](docs/数据导入导出.md)。本轮验证见交付包 `文档/1.3.0-数据导入导出与测试.md`。

数据库仍为v5。完整回归脚本覆盖23个工程；下方1.2.0和更早说明保留为历史记录。

当前交付版新增期初确认与锁定、按生效日期登记余额调整、追加反向调整、历史查询与导出，数据库为v5。

使用入口、权限与口径见 [期初锁定与余额调整](docs/期初锁定与余额调整.md)。当前版本验证见交付包 `文档/1.2.0-期初锁定与深度测试.md`。下方1.1.4说明及旧测试报告为历史记录。

构建：`dotnet build Cashier.slnx -c Release`。

完整回归：`powershell -NoProfile -File .\run-complex-tests.ps1`，覆盖原有19个工程和新增2个测试工程。各测试使用独立合成账套，界面夹具直接加载样式，不触发默认账套启动流程。

## 2026-11-01 报表代码分文件重构

本包在 1.1.4 基础上按业务拆分 `ReportService`，主文件从 1,077 行缩减至 119 行，继续使用 `partial` 和原有统一入口。代码位置与新增报表步骤见 [报表代码结构说明](docs/报表代码结构说明.md)。本次复测结果见包根目录 `文档/报表分文件重构与验证.md`；下方内容及原测试结果保留为历史记录。

本版修复最终排查发现的 8 类问题，数据库结构升级为 **v4**。当前行为、升级说明与验证结果请以交付包 `文档/1.1.4-修复与复测报告.md` 为准。下方及 docs 中的早期版本说明是历史记录。

升级前关闭全部旧版窗口并备份。旧账套打开前会自动生成升级前备份；v4 账套不能直接交给旧程序使用，需要回退时使用升级前的账套备份。

备份/恢复在实际入口检查权限；恢复后退出当前会话。单据和发票采用修订号阻止旧窗口覆盖；导入提交复核启用状态，并与预览共享校验。修改期初追溯影响余额的既有设计保留，界面提示仍适用。
