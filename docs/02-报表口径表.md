# 报表口径表（21 项）

> 1.2.0补充：账户、往来汇总和月度应收应付报表计入按生效日期累计的余额调整，并增加独立调整列；账户资金明细单列调整记录。调整不计入业务收支、项目利润、开票或核销。详见 [期初锁定与余额调整](期初锁定与余额调整.md)。下表保留各报表原有业务来源说明。

通用约定：

- **状态范围**：全部报表只统计 `status='audited'` 的单据；草稿、待审核、已作废一律排除（界面另行标注）。
- **日期范围**：按单据业务日期 `biz_date` 闭区间 `[from, to]`；余额类报表为“截至 to 日”。**期间开票与收款统计**为：发票按登记日期 `reg_date`、收付款按业务日期 `biz_date` 归入期间。
- **金额单位**：元，两位小数，千分位；底层为整数分。
- **含税口径**：除特别说明外，发生额均为**含税金额**（票面/单据金额），不做价税分离。
- **界面 / 导出 / 打印**：三者使用同一个 `ReportService.Build()` 结果，行数、合计完全一致。

## 下钻规则

- 客户应收汇总 / 供应商应付汇总：双击行 → 打开“应收明细 / 应付明细”，自动带入该往来单位与相同期间。
- 账户报表：双击行 → 打开“收支明细”，带入该账户与相同期间。
- 期间开票与收款统计：双击行 → 打开“期间开票与收款明细”，同屏列示该单位发票明细与收付款明细，可一次导出两个工作表。
- 下钻窗口为独立窗口，期间与筛选继承自来源报表。

## 与其他模块的一致性约束

1. **账户报表期末合计 = 全部账户余额之和**（自检项已断言）。
2. **收支月报表净额合计 = 收支年报表净额合计**（同一区间，自检项已断言）。
3. 应收明细“未收”合计 = 应收单金额 − 核销金额；与客户应收汇总的净应收差额等于“未分配收付款 + 期初”。
4. 发票明细的“含税金额”合计只统计有效发票，作废发票单独计数。
