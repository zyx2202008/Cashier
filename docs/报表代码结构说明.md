# 报表代码结构说明

本次按业务拆分 `ReportService` 的源文件，继续使用同一个 `partial class ReportService`。统一入口为 `Build(string id, ReportFilter f)`，报表目录、筛选参数和结果类型保持兼容。

| 文件（位于 src/Cashier.Core/Services） | 职责 |
|---|---|
| ReportService.cs | 报表目录、统一入口、日期校验、公共筛选与参数绑定、公共行映射和读取辅助 |
| ReportService.Cash.cs | 收入/支出/收支明细、内部转账、收支月年报、收支科目汇总 |
| ReportService.Partner.cs | 应收应付明细、客户与供应商汇总 |
| ReportService.Account.cs | 账户资金明细、账户报表、账户月年报及其资金流计算辅助 |
| ReportService.Project.cs | 项目月年利润 |
| ReportService.Invoice.cs | 进销项发票明细、期间开票与收付款统计及其下钻明细 |
| ReportService.MonthlyDebt.cs | 原有月度应收应付统计；本次保持文件内容不变 |
| ReportModels.cs | ReportColumn、ReportRow、ReportResult、ReportFilter、PeriodInvoiceCashDetail |

## 修改现有报表

根据上表找到所属文件，在对应方法内维护查询、参数、列定义、合计和口径说明。将同一报表的这些内容放在一起，便于核查一致性。

## 新增报表

1. 在适合的业务文件中增加报表构建方法。新业务类别可以新建 `ReportService.业务类别.cs`，声明同一命名空间和 `public partial class ReportService`。
2. 在 `ReportService.cs` 的 `Catalog` 中登记可见报表，在 `Build()` 中增加分发分支。
3. 如果有下钻，设置对应的报表编号与筛选条件。
4. 用隔离测试账套检查金额、日期边界、筛选、合计、下钻和导出。

拆分仅调整代码所在文件。现有 SQL、参数绑定、列顺序、金额计算和口径说明原样迁移；数据库结构和版本仍为 v4，应用版本仍为 1.1.4。
