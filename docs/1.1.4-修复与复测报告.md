# Cashier 1.1.4 修复与复测报告

日期：2026-10-31。基于用户提供的 Cashier 1.1.3 源码与交付包修复，交付 Windows x64 自包含程序、完整源码、回归工具及测试证据。

**结论：上一轮报告中的 8 类缺陷均已修复并通过本轮复测。** 最终应用构建为 0 错误、0 警告；补充检查 79 项中 77 项通过、0 项失败、2 项设计观察。原有 433 项基线、19 个测试工程、1,580 项布局检查均通过。

本轮所有数据变更都发生在隔离合成账套内，没有升级或覆盖用户实际业务账套。原 1.1.3 压缩包及此前测试报告保留。

## 2. 版本、账套兼容性与升级

- 程序版本：**1.1.4.0**，主界面显示 v1.1.4。
- 数据库版本：**v4**。
- 新增 `vouchers.revision`、`invoices.revision`、`users.auth_revision` 及 `meta['session.epoch']`，用于编辑冲突和会话失效保护。
- v3→v4 升级前自动生成一致性备份；升级事务失败会回滚。已验证 4 个实例同时升级，不会重复添加字段。
- 恢复先在临时库验证、迁移，完成后才生成当前库安全备份并整体回灌；恢复成功注销会话，确认成功提示后程序自动关闭。

已用原 1.1.3 程序实际生成演示账套，再由修复版升级：23 张单据、5 张发票、3 条核销、2 条发票关联的数量均保持一致；资金合计升级前后均为 **542,599.82 元**。另有 v1、v2、v3 备份迁移、数据和编码保留的回归验证。

**升级操作**：先关闭所有旧版窗口并备份账套；将本包完整解压到新目录，运行 `Cashier/Cashier.exe`，使用原账套目录。软件打开旧账套时自动备份并升级。

**回退规则**：旧程序不能直接打开 v4 账套。需要回退时，关闭程序，把 `backups` 中的升级前备份复制到一个独立目录并命名为 `cashier.db`，再用原旧版程序指定该独立目录；不要仅替换旧 DLL 后继续使用已升级的账套。升级前备份文件名含 `preupgrade-v3-to-v4` 等标识。

## 4. 实际界面核验

实际窗口由独立测试夹具初始化合成账号与明确的账套路径，再展示最终发布的原始 Cashier.dll 窗口，输入和点击通过 computer-use 完成。夹具关闭默认启动逻辑，未访问实际默认账套。正常程序的启动和登录流程另通过原程序内置 QA 路径验证。

1. **旧窗口覆盖**：两个进程都先打开 100 元单据。A 保存 250 元后，B 仅改摘要并保存，出现“单据已被其他窗口修改，请关闭编辑窗口，刷新后重新打开”。直接读库仍为 25000 分，原摘要未被覆盖。
2. **只读权限**：界面显示只读角色，“立即备份”“恢复选中备份”均为 disabled；实际业务方法也拒绝越权调用。
3. **合法恢复**：管理员恢复合成账套成功，备份之后新增的 50 元测试收入从当前账套移除，恢复前安全备份存在；确认成功提示后窗口和测试进程自动关闭。

截图、控件状态和前后数据库读取结果在 `测试结果/界面/`。

## 5. 测试用例随修复行为的调整

为保持用例与新版本一致，测试源做了以下明确调整，并保留随包供复查：

- 数据库版本断言改为当前 v4，程序集版本断言改为 1.1.4。
- 恢复后重新登录，再测试后续写入。
- 权限场景创建真实账号并登录，替代手工构造用户对象。
- 无效备份在覆盖前拒绝时，不要求生成恢复前安全备份；有效备份另行验证安全备份与恢复。
- 混合导入文件在预览中已标明错误行后，预期仅导入正常行。

原有 433 项基线保留数量和业务检查；本轮增加对真正备份恢复入口的权限检查，避免此前只测试权限函数的盲区。

## 6. 已声明设计与未覆盖范围

**D-01 期初规则保留为设计观察**：修改期初仍会追溯影响历史余额。界面已有相应提示，早期文档也声明缺少独立期初锁定；本轮没有改变会计口径。这对应 2 项 OBSERVE，不计为未修复缺陷。

未实测真实打印机出纸、不同 Windows 版本和真实显示 DPI、网络共享盘/多机器并发、断电/磁盘满/系统崩溃、目录 ACL 拒绝以及超过 2 万行单文件导入。布局测试使用应用内尺寸和布局缩放。

## 7. 交付与复现

`Cashier-1.1.4-Windows.zip` 包含可运行程序、完整源码、修复状态清单、测试记录、界面证据和回归脚本。解压后直接运行 `Cashier/Cashier.exe`。

重新执行补充回归需要 PowerShell 7 和 .NET 10 SDK：

```powershell
pwsh -File .\复现测试\重跑回归.ps1
```

追加原有 433 项基线：

```powershell
pwsh -File .\复现测试\重跑回归.ps1 -IncludeBaseline
```

每次生成独立随机测试目录。应用本身自包含运行环境，普通使用不需要 SDK。
