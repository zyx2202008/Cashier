# 数据导入导出（1.3.0）

入口：**系统工具 → 导入导出**。页面有“导入预览”“导入批次记录”“基础资料整理”“整账套迁移”四页。

## 换电脑或完整迁移

1. 在原电脑以管理员或会计登录，打开“整账套迁移”，点击“导出整账套”，保存为`.cashier`文件。
2. 将文件复制到新电脑。新电脑先解压运行Cashier，以管理员登录一个账套（全新账套初始为`admin / admin888`）。
3. 在“整账套迁移”选择该文件，核对来源账套、导出时间与记录数。
4. 点击“导入为新账套”，选择存放位置。软件会显示将创建的新文件夹，确认后导入。
5. 点击“打开导入的账套”，用**来源账套原有的账号、密码**登录。

整账套文件包含全部基础资料、五类单据及状态、发票、核销及历史关联、期间、期初锁定、余额调整、账号角色、设置和操作日志。导入创建新账套，不与当前账套合并，也不覆盖已有文件。迁移功能不包含软件安装目录下的程序、运行日志、外部文件或其他账套的备份目录。

导出使用数据库一致快照。导入前检查文件清单、摘要、记录数、数据库结构、索引、保护触发器和外键；复核文件是否与预览时一致。先在临时目录验证和升级，再完成新账套目录的提交。账号会话使用新代次，导入账套需重新登录。

文件包含完整账务与账号验证数据，请妥善保存。管理员可以导入整账套，管理员和会计可以导出。

## Excel新增或批量修改基础资料

支持：**资金账户、客户与供应商、收入支出科目、部门、项目、经办人**。

### 新增

1. 在“基础资料整理”选择资料类型，点击“下载空白模板”。
2. 在“资料”工作表填写；详细规则在“填写说明”页。新增行的记录编号留空，客户供应商编码也留空，由软件生成。
3. 启用列填`1`或`0`。项目引用的部门必须先存在；可先导入部门，再导入项目。
4. 选择Excel并预览，核对每行新增、修改、不变或错误。没有错误后，点击“确认导入”。

### 修改

1. 选择资料类型，点击“导出当前资料”。
2. 在原行修改名称、联系人等资料；保留记录编号和隐藏校验列。新增行可填在末尾，编号留空。
3. 回到软件选择文件并预览，确认后保存。完成一轮修改后，下一轮请重新导出当前资料。

保留的校验信息用于防止旧文件覆盖新资料。文件来自其他账套、原记录已被修改、重复编号等情况会标错。整账套迁移保留账套身份，迁移后的同一账套仍可识别其原有资料导出文件。

### 导入规则

- 所有有效变更在同一事务提交；有错误则整批不导入。中途失败时，已处理行、审计日志和批次记录一起回滚。
- 预览不会保存资料变更。同一文件中的重复编号会标错；与已有资料完全相同的新增行跳过。
- 相同编码或同名资料的数据有差异时，不会直接按名字覆盖；需要从本账套导出原记录后修改。
- 期初锁定后，Excel也不能修改账户或往来期初。即使预览后才锁定，提交时仍会重新检查。
- 记录编号用于识别原资料，不能靠更改单号改写其他记录；没有删除操作，需要停用时将启用列改为`0`。
- 编码、电话等按文本格式保存，保留前导零。公式不作为资料导入，请填写具体值。
- 单次基础资料最多10,000行、文件20MB。管理员和会计可以使用此页，出纳和只读账号不能更改基础资料。
- 导入失败或原资料发生变化后，请修正文件或重新导出、预览。可导出逐行校验结果。

## 业务单据与发票

“导入预览”保留原有收入、支出、销项发票、进项发票的Excel模板与校验流程；业务收支导入后为待审核。报表和业务列表保留原有Excel导出。

本次新增Excel编辑回导针对上述六类基础资料，不把已审核单据、已关账历史、核销和余额调整当作可任意改写的Excel数据。完整保留它们请使用整账套迁移；业务更正沿用原有审核、期间及余额调整流程。

本版本应用为1.3.0，数据库仍为v5。1.2.0账套无需结构升级；更旧版本仍按现有规则升级并自动备份。
