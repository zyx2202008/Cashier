# 使用说明

## 1. 启动

1. 解压发布包（或直接使用 `dist/app` 目录），双击 **`Cashier.exe`**。
2. 首次启动自动在 `%APPDATA%\Cashier\` 创建账套数据库、备份目录与日志目录。
3. 默认管理员：**admin / admin888**（登录后请立即在“系统工具 → 账套与打印设置 → 修改我的密码”中修改）。
4. 目标电脑**无需安装 .NET**：发布包为 x64 自包含版本，含运行时。

> 便携用法：`Cashier.exe --data-dir D:\我的账套`，数据会保存在指定目录（例如 U 盘），实现“绿色版”。

## 2. 数据目录

| 路径 | 内容 |
|---|---|
| `%APPDATA%\Cashier\cashier.db` | 账套数据库（正式数据） |
| `%APPDATA%\Cashier\backups\` | 备份文件 `cashier-yyyyMMdd-HHmmss-*.db` |
| `%APPDATA%\Cashier\logs\` | `startup.log`（启动/迁移）、`error.log`（异常） |
| `%APPDATA%\Cashier\templates\` | 预留模板目录 |

界面左下角「数据目录」按钮与“备份与恢复”页的「打开备份目录」可直接定位。

**不要在软件运行时用资源管理器复制 `cashier.db`**——WAL 模式下会漏数据。请使用「备份与恢复 → 立即备份」。

## 4. 日常操作流程

### 4.1 建立基础资料
1. “基础资料 → 资金账户”：录入银行/现金账户与**期初余额**。
2. “基础资料 → 客户与供应商”：录入往来单位；有历史欠款的填写**期初应收/应付**（负数表示预收/预付）。
3. “基础资料 → 收入支出科目 / 项目 / 部门 / 经办人”：按需维护。
4. 已被单据引用的资料只能“停用”，不能删除；历史单据仍可正常查看。

### 4.2 记账
| 业务 | 入口 | 业务性质 |
|---|---|---|
| 收到客户货款（已有应收） | 收入记账 | 客户回款 |
| 收到客户预付款 | 收入记账 | 客户预收 |
| 现收收入（当场收款开票） | 收入记账 | 现收收入 |
| 确认应收（未收款） | 应收管理 → 新增 | 应收单，勾选“计入项目收入” |
| 支付供应商货款 | 支出记账 | 供应商付款 |
| 预付供应商 | 支出记账 | 供应商预付 |
| 确认应付（未付款） | 应付管理 → 新增 | 应付单，勾选“计入项目成本” |
| 账户间调拨 | 内部转账 | 选转出/转入账户；手续费自动生成支出单 |

单据保存后为**待审核**，审核后才计入账务。可在“审核中心”批量审核。

### 4.3 核销
“应收管理/应付管理”选中一张已审核单据 → 工具栏「核销」：
- 选择一笔或多笔业务单据 → 填分配金额 → 「分配到选中单据」；
- 或直接「按日期先后自动分配」；
- 已核销明细可「取消选中核销」（需填原因）。

### 4.4 发票
“销项发票/进项发票” → 「登记发票」→ 填发票号码、含税金额、税率（不含税与税额自动计算并校验）→ 保存。
选中发票 → 「关联业务」→ 选择已审核的可开票业务单据 → 填关联金额。
发票**不影响资金余额**；「作废」前需先解除全部关联。

### 4.5 报表
左侧“报表 · xxx”共 19 张；选择期间/往来单位/项目/账户 → 查询。
- 「期间开票与收款统计」支持销项/进项切换，快捷期间（本月/上月/本季度/本年度/自定义）；默认本月 1 日 ~ 今日，结束日含当日；
- 汇总类报表双击行可**下钻**到明细；「期间开票与收款统计」下钻后同屏显示发票与收付款明细，可一次导出两个工作表；
- 「导出 Excel」生成 .xlsx（含标题、期间、口径、合计、备注）；
- 「打印」打开预览，可多页打印（表头重复、页码、期间与口径）。

### 4.6 导入
“系统工具 → 导入导出”：
1. 先「下载收入模板 / 下载支出模板」（含填写说明与可选编码页）；
2. 「选择 Excel 文件…」→ 查看预览（每行状态：可导入 / 重复 / 错误+原因）；
3. 「确认导入」→ 写入为**待审核**单据，并记录导入批次。
相同数据的重复行会被标记“重复（跳过）”，不会静默重复入账。

### 4.7 备份与恢复
- 「立即备份」生成一致性备份；
- 选中备份 → 「恢复选中备份」：会先校验完整性、自动备份当前库，再回灌；恢复后需重启软件。

### 4.8 期间
“系统工具 → 期间管理”：输入 `yyyyMM` → 「关闭期间」。关闭后该月不可新增/修改/反审核。
「重新开启」需填写原因并写入日志。

## 5. 常见问题

| 问题 | 处理 |
|---|---|
| 提示“该期间已关闭” | 期间管理中重新开启（需原因），或改用开放期间 |
| 提示“存在核销记录/发票关联” | 先在对应页面取消核销 / 解除发票关联，再反审核或作废 |
| 提示“该账户已被业务引用，不能删除” | 改为“停用” |
| 忘记密码 | 管理员在“用户与权限”中重置；若管理员密码丢失，需技术支持处理数据库 |
| 余额与手工账不符 | 检查期初余额、是否有待审核单据未审核、是否有跨期单据 |
| 换电脑 | 拷贝整个 `%APPDATA%\Cashier` 目录，或在新机恢复备份 |

## 6. 卸载

删除程序目录即可。数据保留在 `%APPDATA%\Cashier`，如需彻底清除请手动删除该目录（**不可恢复，请先备份**）。
