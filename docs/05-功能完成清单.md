# 功能完成清单

图例：✅ 已实现并验证　⚠️ 已实现但有范围限制　❌ 未实现

## 一、业务记账

| 功能 | 状态 | 说明 / 验证方式 |
|---|---|---|
| 收入记账 | ✅ | 5 种业务性质（现收/回款/预收/供应商退回/其他）；自检验证回款不重复计收入 |
| 支出记账 | ✅ | 5 种业务性质（现付/付款/预付/退还客户/其他） |
| 应收记账 | ✅ | 应收单不涉及资金账户；可标记是否计入项目收入、是否可开票 |
| 应付记账 | ✅ | 应付单不涉及资金账户；可标记是否计入项目成本 |
| 内部转账 | ✅ | 同账户拒绝、总资金不变、手续费独立成支出单（自检 D 全部通过） |
| 单据编号 | ✅ | 前缀 + 日期 + 3 位流水，`UNIQUE` 约束 |
| 草稿/待审核/审核/反审核/作废 | ✅ | 状态机 + 事务 + 受影响行数校验；重复审核被拒（自检 F） |
| 已审核只读 | ✅ | 界面禁用 + 业务层拒绝修改 |
| 附件 | ❌ | 本次未实现单据附件上传（备份只覆盖数据库） |

## 二、发票管理

| 功能 | 状态 | 说明 |
|---|---|---|
| 销项/进项发票登记 | ✅ | 类型、号码、代码、往来单位、登记/交票日期、含税/不含税/税额、税率、内容、备注 |
| 发票查询/修改 | ✅ | 已关联业务后不允许改金额；已作废不可改 |
| 发票作废 | ✅ | 需先解除关联；保留记录 |
| 重复校验 | ✅ | 同类型有效发票号码唯一（部分唯一索引）；作废后可复用（自检补充项） |
| 价税分离与校验 | ✅ | `不含税 + 税额 = 含税` 整数分精确校验 |
| 发票与业务关联 | ✅ | 一票多单、一单多票；金额上限双重校验；重复关联被拒 |
| 已开票/未开票统计 | ✅ | 客户应收汇总报表 + 关联窗口 |
| 多税率 / 多行明细 | ⚠️ | 仅支持整张单一税率；多税率需拆票（已在业务规则声明） |
| 发票 Excel 导入 | ❌ | 仅单据导入；发票需在界面登记 |

## 四、报表（19 项）

全部 ✅：收入明细、收支明细、支出明细、应付明细、应收明细、内部转账明细、收支月报表、收支年报表、科目汇总、项目月利润、项目年利润、供应商应付汇总、客户应收汇总、期间开票与收款统计、账户报表、账户月报表、账户年报表、销项发票明细、进项发票明细。

- 每张报表均有：真实 SQL 查询、筛选（期间/往来/项目/账户）、合计、导出 xlsx、打印预览与打印。
- 汇总类报表支持下钻到明细（客户/供应商汇总 → 应收/应付明细；账户报表 → 收支明细）。
- 期间开票与收款统计：销项/进项方向切换、快捷期间、红票负数冲减、蓝/红/净张数、票款差额；双击行打开发票与收付款双明细并可导出两个工作表。
- 自检断言：19 张报表全部可生成；月表净额合计 = 年表净额合计；账户报表期末合计 = 全部账户余额。

## 五、系统工具

| 功能 | 状态 | 说明 |
|---|---|---|
| Excel 模板下载 | ✅ | 收入/支出模板，含“填写说明”“可选编码”两页 |
| Excel 导入 | ✅ | 真实读取 xlsx；表头校验、逐行校验、预览、错误行原因、重复行跳过、批次记录、导入为待审核 |
| Excel 导出 | ✅ | 报表与列表页均可导出；金额为数值格式、日期为文本、含合计与口径 |
| 打印预览 / 打印 | ⚠️ | 自绘 FixedDocument：A4 纵/横、表头跨页重复、页码、期间与口径、金额不截断；实际打印走系统打印对话框。**本机无物理打印机，仅验证预览渲染与打印对话框** |
| 打印设置 | ⚠️ | 使用 Windows 打印对话框（打印机、纸张、份数、方向）；未提供应用内模板编辑器 |
| 本地用户与角色 | ✅ | 4 角色；PBKDF2 密码；业务层权限校验（自检：出纳不能审核） |
| 审核 / 反审核 | ✅ | 事务 + 下游依赖检查 + 原因记录 |
| 操作日志 | ⚠️ | 记录操作者/时间/动作/单据号/原值/新值/原因；界面无删除入口。**属应用层追加日志，非防篡改审计**（未做哈希链/签名） |
| 账套基础设置 | ✅ | 账套名称、单位名称、分页条数；单账套（一个数据目录一个账套，可用 `--data-dir` 切换） |
| 备份 / 恢复 | ✅ | 在线备份 API（WAL 一致）；恢复前校验 + 自动备份 + 回灌；自检 H 完成一次真实备份→修改→恢复→核对 |
| 备份位置设置 | ⚠️ | 默认 `%APPDATA%\Cashier\backups`，可打开目录；未提供界面内更改路径（可用 `--data-dir` 整体迁移） |
| 期间关闭 / 重新开启 | ✅ | 关闭后禁止写入；重开需原因并写日志（自检覆盖） |

## 六、非功能要求

| 要求 | 状态 | 证据 |
|---|---|---|
| Windows x64 自包含 EXE | ✅ | `dist/app/Cashier.exe`，257 个文件，无需安装 .NET |
| 单机、无网络依赖 | ✅ | 无任何 HTTP/云调用；SQLite 本地文件 |
| 关闭/重启后数据仍在 | ✅ | 自检 G：重开数据库后单据数、账户余额、往来余额一致 |
| 金额 decimal + 整数分 | ✅ | `Money` 全量转换；SQLite 中金额列均为 INTEGER |
| 统一舍入 | ✅ | `MidpointRounding.AwayFromZero`（自检 E） |
| 数据目录可写且不被升级覆盖 | ✅ | `%APPDATA%\Cashier`，非安装目录 |
| 数据库升级前备份 | ✅ | `Database.EnsureCreated` 中先备份再迁移 |
| 演示账套与正式账套分离 | ✅ | 正式账套为空库；演示账套在 `dist/demo-data`（`--seed-demo` 生成） |
